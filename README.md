## ⚡ Getting Started

### Clone the repository

```bash
git clone https://github.com/shanusingh01/CODSOFT.git
```

### Navigate into the project folder

```bash
cd CODSOFT
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```
